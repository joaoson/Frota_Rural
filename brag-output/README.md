# Frota Rural launch video

22 seconds · 1920×1080 · 30 fps · Portuguese · music and SFX, no narration.

- `brag.mp4`: finished video, with the chosen poster baked into frame zero.
- `brag.jpg`: standalone thumbnail.
- `share-copy.txt`: ready-to-post caption.
- `brag-plan.md`: product research and storyboard.
- `composition-brief.md`: creative brief and source mapping.
- `composition/`: editable Hyperframes project and local media.

Run `npm run check`, `npm run dev` or `npm run render -- --output ../brag.mp4` inside `composition/`.

Source images, mascot and UI copy come from the Frota Rural project. The interface is a source-derived animation with illustrative listing and reservation data, rather than a recording of a live transaction. Intermediate approval and payment steps are condensed.

Music: Happy Beats / Business Moves vol. 12, ende.app, bundled with latent-spaces/brag. SFX: Kenney, bundled with the same skill. Motion: adapted line-by-line-slide primitive from Hyperframes. Fonts: Epilogue and Inter.
